# Language support

English is the default. Choose **English** or **简体中文** in the main header.
The choice is saved in this browser under `gamecoach-language`. An unavailable
browser store does not prevent switching for the current page.

The UI, draft editor, role and rule labels, local demo, errors, starter prompts,
memory controls and default analysis guidance follow the selected language.
Skill requests the same response language from Gemini; an explicit request for
another language takes priority. Changing languages stops a response in progress.
Existing conversations, personal memory edits, user names and profile values
retain their original text. Language switching does not change champion IDs,
picks, bans, users or conversation history.

## Files

- `translations.js`: English copy keyed by the existing Chinese source strings.
- `i18n.js`: locale persistence, formatting and initial HTML translation. Only
  original static HTML is scanned; personal text is never scanned for replacement.
- `data.js`: localized catalogue views, keeping the source catalogues unchanged.
- `../resources/lol/english.js`: official English champion names and titles.
- `../memory/locales.js`: translations of untouched starter memories. Editing or
  deleting a memory keeps its existing behavior; custom writing is preserved.

Champion names and titles match the existing Riot Data Dragon 16.20.1 snapshot:
[official English catalogue](https://ddragon.leagueoflegends.com/cdn/16.20.1/data/en_US/champion.json).
The Wild Rift exclusive Norra uses her
[official champion page](https://wildrift.leagueoflegends.com/en-us/champions/norra/).
This change localizes names; it does not update game balance data or translate
the underlying Chinese ability snapshots. Skill asks the model to explain those
references in the selected language using official proper names.

No build step, npm, backend, translation API or CDN is required. The bundled
scripts work when opening the HTML locally and when serving it on GitHub Pages.

# memory

独立的本地长期记忆模块。保存值得跨聊天复用的分析经验与个人偏好，按问题取出精简内容作为 user 级参考上下文。没有 API 的“弱权重”数值参数，不训练或修改模型参数，也不声称复制了 ChatGPT 内部实现。

## 文件

- `defaults.js`：七条初始分析经验，包括用户提出的五个方向及两条补充。只在用户没有记忆数据时初始化，不覆盖后续编辑或复活删除项。
- `analysis-preferences.md`：上述初始记忆的可读说明。
- `index.js`：数据规范、旧玩家资料迁移、增删改、Markdown 文档导出。
- `retrieve.js`：按问题选取相关记忆与控制输入长度。
- `commands.js`：明确的“记住：……”和“忘记：……”本地操作；不增加模型调用。
- 前端 `memory-ui.js`：查看、编辑、新增、暂停、删除、撤销本次删除与导出。

## 数据与隐私

每个本地用户拥有独立的 `memory: { version: 1, enabled, entries }`。每条有稳定编号、标题、正文、适用场景、来源、启用状态与时间。分析经验和个人记忆共用管理界面，来源保持可见。

记忆随用户保存于浏览器；连接 `users/` 文件夹后，包含在原有 `<用户 ID>.json` 里同步。用户备份 JSON 可完整导入恢复记忆；“导出记忆文档”额外生成可阅读的 Markdown，不会上传。导出的 Markdown 是阅读副本，当前通过管理界面编辑，尚无 Markdown 文件导入或外部文件改动监听。

旧玩家资料首次转换成独立记忆条目。原 profile 字段为表单与旧备份兼容保留，Skill 不再读取它；保存表单时只有改变的字段更新对应个人记忆。未改变的字段不会覆盖在记忆面板里的编辑，也不会复活已删除项。新用户不预设位置。常用位置、英雄池、段位和自评只在明确问到个人经验时选取；偏好仍按场景参考，不固定本局位置或候选英雄。

没有完整复制用户对象；API Key、用户 ID、文件路径及任意字段不会因迁移被当作画像记忆发送。用户自己输入的记忆可能包含个人信息，请在界面检查后决定保存和使用。

## 接入

```js
GameCoachSkill.run(messages, {
  context: { draft, memory: currentUser.memory },
  mode: 'quick',
});
```

Skill 通过 `GameCoachMemoryRetrieval.select` 获取一次精简参考，放在最新问题附近。当前问题与游戏事实优先，记忆不用逐项执行。返回的 `usedMemories` 记录本次带入的编号和标题，页面可展开检查；它说明提供了哪些背景，不保证模型每条都采用或回答已核实。

关闭总开关不删除数据，后续请求不再附入记忆。删除默认条目后刷新不会重新加入。删除记忆不会同步删除已有聊天原文；原文或旧模型回答仍可能出现在最近历史里。管理面板可撤销最近一次删除，聊天“忘记”操作通过正常用户备份恢复。

## 更新方式

- 管理界面可以手动编辑全部条目，单独暂停，也可以关闭整个记忆模块。
- 聊天输入 `记住：讨论辅助时，希望多探索大胆配合`，立即在本地保存并显示“本地记忆”回执，不调用 Gemini。
- `忘记：analysis-support` 可按编号删除；按文字查找时，只有唯一匹配才执行。
- 普通战报、一次输赢和临时选人不会自动变成永久偏好。当前没有让另一个 AI 在后台猜测、整理用户记忆；本阶段实现明确保存，不承诺 ChatGPT 式全自动隐式记忆提炼。

## 上下文与 Token

当前按中文场景词与少量短追问关联筛选，最多六条；参考正文总预算 1400 字符，每条最多 400 字符，超出标节选。加说明通常不超过 1600 字符。这是字符预算，不是精确 Token 计数。闲聊、连接状态询问不会仅因已选 BP 就加载分析记忆。

前端仍取最近二十条有效历史，排除失败、演示及本地记忆命令回执，并对重复阵容去重。这是历史长度限制与选择，不是自动语义压缩；当前尚无 Codex/Responses 那样的 compaction。被取用的记忆仍消耗模型输入 Token，记忆摘要或检索本身不提供免费无限上下文。

参考设计概念：[OpenAI 官方记忆与压缩示例](https://developers.openai.com/cookbook/examples/agents_sdk/building_reliable_agents_memory_compaction)。项目仍调用原有 Gemini；不依赖 OpenAI SDK 或服务。

## 验证

`node --test tests/*.test.cjs` 覆盖旧数据迁移、个人资料不直接入 Skill、相关性与预算、暂停/删除、重新加载不复活、用户隔离、备份恢复、本地记忆命令及实际请求格式。真实模型是否正确采用经验，需要用自己的 Key 验收。

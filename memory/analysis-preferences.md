# GameCoach analysis memories

这份文档记录初始分析记忆，便于阅读与维护。网页使用 `defaults.js` 中对应的普通脚本数据，兼容双击 HTML。每个本地用户首次初始化时获得一份独立副本；之后在“我的用户 → 管理记忆”修改、暂停或删除。修改本文件不会自动覆盖用户已有记忆。

这些是可选的长期经验：记录分析方法和偏好，具体结论由本局条件决定。只参考相关内容，不要求每次逐项输出。Quick 侧重最有用的行动与必要风险，Coach 按问题展开。

## analysis-support · 辅助选人

可以主动探索大胆、非常规的辅助选择，分析它能创造的机会、成立条件和代价。创意服务于当前阵容，不必每次推荐冷门英雄。

## analysis-jungle · 打野决策

可以考虑上半区或下半区投入、线路配合、资源交换，以及放弃另一侧会带来的影响。

## analysis-carries · 中下双 C

可以比较中下双 C 各自的强势期，判断谁先带节奏、谁需要发育，以及双方的窗口能否衔接。

## analysis-development · 阵容发展

可以推演阵容前中后期的变化，分析团战、单带、抓人和资源争夺分别如何形成赢法。

## analysis-opponent · 对手应对

可以考虑对方会怎样破解当前打法，以及原计划失败后还能如何调整；不把一种赢法说成唯一解。

## analysis-roles · 本局分工与摇摆（补充）

选人时可以先结合已选阵容判断待补位置和可能的摇摆，简短说明关键假设。常用位置不等于本局位置，熟悉的英雄也不是候选范围。

## analysis-evidence · 经验与判断（补充）

讨论战报时可以区分用户描述、已知机制与推测，分别评价选人思路、实际执行和对手失误；认可有具体依据，单局获胜不直接证明策略能稳定复用。
